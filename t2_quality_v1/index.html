怎么看这一页（流程 · 术语 · 每个选项的后果）

T2 Grounding 复核判的不是题目对错：题干和答案文字都已冻结，你要判的是 「答案里的每一条，在选定的图像上到底看不看得到」。流水线已自动判过一轮并给出倾向，你做的是确认或推翻。

流程（按顺序）

  1. 读英文 Question + Gold：知道这道题在问什么、答案里有几条。
  2. 看源图：题目原本用的帧。
  3. 逐 Element 裁决：答案里的每一条都要单独四选一（漏一条就不能批准）。
  4. 判「接受视觉支持」的要素，再勾出它的 supported evidence 和对应帧。
  5. 整题做 Item decision 三选一；选「批准 grounded frames」时勾最终帧（＝下版给模型看的 panel）。
  6. 页面顶部「复核结果」框复制或下载，交给 CLI validate（最终门禁）。

证据卡上的两组标签

mode 决定证据强弱：blind 是模型只看图时写下的观察（独立证据）； compare 是给了报告之后的对齐结果（容易被报告带话，单独不足以证明）。status 说明两侧是否指向同一帧：

mode + status含义
blind + blind_only_observation盲读观察·只有盲读提出（需你看图定）
blind + blind_supported_observation盲读观察·已被对照在同一帧上印证（较强）
compare + compare_only_candidate对照候选·只在对照阶段出现（最弱，单独不能批准）
compare + blind_supported_match对照结论·盲读在同一帧也看到（最强，可视觉批准）
compare + conflict_review两侧冲突·待人工

每张证据卡下方的帧分四堆，只有最后一堆能勾为视觉证据：

帧堆含义
frame_ids盲读观察帧
blind_frame_ids盲读帧
compare_frame_ids对照帧
supported_frame_ids交集·可批准帧（只有这些能勾）

卡片末尾的 supported ＝ 这条证据在系统里已被列为该要素的可批准证据； context/risk ＝ 只作参考，勾了会报「evidence 不属于 binding」。
